## 简介

一本系统讲解大模型（LLM）知识的单文件手册，覆盖从基础原理到工程落地的完整链路，适合零基础入门与进阶学习。

- **单文件零依赖**：一个 HTML 文件即可离线阅读，无需安装任何环境
- **覆盖完整链路**：从原理（Transformer）到落地（部署/Agent/MCP）
- **中文讲解**：面向中文读者的自学友好排版
