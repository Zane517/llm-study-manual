## 简介

一本系统讲解大模型（LLM）知识的自学手册，覆盖从基础原理到工程落地的完整链路，适合零基础入门与进阶学习。

- **中英双语**：中文版 `index.html` / 英文版 `index_en.html`，侧边栏一键切换语言
- **覆盖完整链路**：从原理（Transformer / Attention）到落地（部署 / Agent / MCP）
- **多文件结构**：CSS / JS 独立文件，便于维护和二次开发
- **离线可用**：下载后直接用浏览器打开，无需安装任何环境

1. 克隆仓库：`git clone https://github.com/Zane517/llm-study-manual.git`
2. 用浏览器打开 `index.html`（中文）或 `index_en.html`（英文）
